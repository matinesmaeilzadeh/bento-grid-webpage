# Bento Grid Webpage

A responsive **Bento Grid** webpage built with **HTML5** and **CSS3**, based on the [Frontend Mentor Bento Grid Challenge](https://www.frontendmentor.io/challenges/bento-grid-RMydElrlOj).

## 🛠️ Built With

- HTML5
- CSS3
- CSS Grid
- Media Queries

## ✨ Features

- Responsive design
- Bento Grid layout
- Desktop, tablet, and mobile support
- Responsive images
